# 士气章设计工具

二次元风格六边形士气章设计软件，支持人物立绘破框效果，导出300DPI印刷级PNG。

## 快速开始

```bash
# 安装依赖
npm install

# 开发模式（浏览器预览）
npm run dev

# 桌面软件开发模式（Electron）
npm run electron:dev

# 打包成 .exe / .app
npm run electron:build
```

## 功能

- ⬡ 六边形双层金属边框（5.2×6cm 印刷尺寸）
- 🎨 背景渐变色自由调节
- ✨ 放射线背景开关
- 🧍 人物立绘导入 + 大小/位置调整（支持破框效果）
- 📝 主标牌文字编辑（位置可选：顶/底/中）
- 💾 导出高清 PNG（300DPI，可直接送厂印刷）

## 破框效果说明

人物立绘会自动渲染在内金框之上，只要图片本身有透明背景（PNG格式），
人物就会"突破"框架，产生视觉冲击的破框效果。

建议使用：**透明背景 PNG 格式的立绘**

## 印刷规格

| 参数 | 数值 |
|------|------|
| 成品尺寸 | 5.2 × 6 cm |
| 分辨率 | 300 DPI |
| 导出格式 | PNG（RGBA） |
| 像素尺寸 | 614 × 709 px |
