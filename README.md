# 蚀刻章设计工具

> 二次元风格六边形士气章/蚀刻章设计桌面软件，支持图层系统、人物立绘破框、可拖拽文字和几何图形，导出300DPI印刷级PNG。

---

## 功能一览

- **六边形画布** — 宽高独立调节，尖顶朝上，透明背景导出
- **边框系统** — 外框、间距带、内框三层独立配色，内细线可调
- **图层面板** — 类似PS的图层管理，支持显示/隐藏、上下排序、删除
- **背景图层** — 15种背景模式：明日方舟风、星空、纯色、线性/径向/角度渐变、蜂巢网格、斜线条纹、自定义图片等
- **装饰图层** — 13种可拖拽几何图形（圆、矩形、三角、六边形、星形、盾牌、月牙等），支持填充/描边/旋转/缩放
- **人物图层** — 导入PNG立绘，破框效果（突破内框），可调大小和位置
- **文字图层** — 可拖拽文本框，支持多行，8种花体字体，360°旋转，角点缩放
- **自动保存** — 每5秒防抖保存，每60秒定时备份，保存至 `桌面/Rhoxane/蚀刻章/`，启动时自动恢复
- **导出** — 透明背景PNG，300DPI印刷规格，导出时自动隐藏控制框

## 快速开始

### 环境要求

- Node.js v18+
- npm v9+

### 安装依赖

```bash
npm install
```

### 开发模式（浏览器预览）

```bash
npm run dev
```

### 桌面软件开发模式

```bash
npm run electron:dev
```

---

## 打包成 .exe / .app

### Windows

**方式一（推荐）：先开启开发者模式**

`Win + I` → 搜索「开发者模式」→ 打开 → 然后运行：

```cmd
npm run electron:build
```

**方式二：跳过代码签名（无需管理员）**

```cmd
npm run electron:build:win
```

或者：

```cmd
set CSC_IDENTITY_AUTO_DISCOVERY=false && npm run electron:build
```

打包完成后安装包在 `dist-electron/蚀刻章设计工具 Setup 1.0.0.exe`

### macOS

```bash
npm run electron:build
```

打包完成后在 `dist-electron/蚀刻章设计工具-1.0.0.dmg`

### 下载慢？用国内镜像

在 `.npmrc` 里取消注释镜像地址：

```
ELECTRON_MIRROR="https://npmmirror.com/mirrors/electron/"
```

然后删掉 `node_modules` 重新 `npm install`。

## 使用说明

### 图层操作

| 操作 | 方式 |
|------|------|
| 新增图层 | 左侧面板顶部「+背景 / +装饰 / +人物 / +文字」 |
| 选中图层 | 点击图层列表中的图层名 |
| 上下排序 | 图层右侧 ↑ ↓ 按钮 |
| 显示/隐藏 | 图层右侧 👁 按钮 |
| 删除 | 图层右侧 ✕ 按钮 |

### 文字 / 装饰几何交互

| 操作 | 方式 |
|------|------|
| 移动 | 在预览区点住拖动 |
| 缩放 | 拖动白色角点/边点 |
| 旋转 | 拖动顶部金色圆点 |
| 选中 | 点击图形区域（需先在图层面板选中对应图层） |

### 自动保存

保存位置：`桌面/Rhoxane/蚀刻章/`

| 文件 | 说明 |
|------|------|
| `autosave_project.json` | 完整项目配置，每次操作5秒后自动更新 |
| `autosave_preview.png` | 最新预览截图 |
| `backups/` | 带时间戳历史备份，最多保留20个 |

> ⚠️ 图片素材（立绘、背景图）无法写入JSON，恢复后需重新上传，其他所有参数完整保留。

### 导出

点击左上角「↓ 导出」，选择保存位置，输出透明背景PNG（300DPI）。

## 印刷规格参考

| 参数 | 默认值 |
|------|--------|
| 画布尺寸 | 5.2 × 6 cm |
| 分辨率 | 300 DPI |
| 导出格式 | PNG（透明背景 RGBA） |
| 默认像素 | 约 1228 × 1417 px |
